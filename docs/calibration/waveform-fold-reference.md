# Triangle fold and hybrid source network

This is a source-model calibration candidate. The original captures and prepared `d9d1204`
comparison build remain the baseline. These changes do not establish blind equivalence.

## Physical mechanisms and provenance

The triangle source is board1's Q2 fold and Q1 follower. Its old DC table agrees with the
transcribed circuit, but the real reference's simultaneous MIX recordings contain less
high-harmonic energy. The difference follows harmonic number across84,173 and357Hz, while
the saw control is close to1/n. A shared fixed-frequency capture/output low-pass cannot
account for that pattern. MAIN's additional distortion must be kept separate: the historical
triangle's MAIN H2 stands about3.2dB above MIX, while H3 is about1.3–1.75dB lower.

`Q2N3392`'s reverse beta, BR=4, was an unspecified generic assumption in `mm-devices.lib`;
the source datasheet specifies the gain bin and capacitance, not reverse beta. A separate
Q2-only `Q2N3392_TRI_REFERENCE` model uses BR=0.35. The common model and all its other
instances remain unchanged. This is an equivalent device-model inference, not a measurement
of the installed transistor. Oscillator R3 remains the drawing's10.7K1% part.

The hybrid combines sources through front-panel R03047K and R03110K on drawing1448.
Table7-2 FRONT PANEL ASSEMBLY specifies each as±5%,1/2W: parts852-512473-001 and
852-512103-001 respectively. The primary scan is `replacement-parts-700.gif`, SHA256
`f992dbaa768ea0fa1924073de61609da0b28d57a80887c3e015faa4289f960a0`.
R031 is distinct from oscillator-board R31. The reference-equivalent R031 is9.53K(E96),
−4.7% from the drawing; R030 stays47K. The installed reference part has not been measured.
`front-waveform.lib` keeps the drawing's10K default and takes a calibrated value explicitly.
The real-time source and LO use the same calibrated network constants.

## Selection and exclusions

The Q2 hypothesis was initially explored against all three historical pitches. Final BR
selection was frozen on triangle MIX84.29Hz H2–24 only. The other two pitches are cross-pitch
consistency checks, not blind statistical holdouts. The BR-only candidate improved triangle
but made the hybrid brighter; that rejected intermediate build and its regression are kept.

The subsequent R031 stage used hybrid MIX84Hz H2–24 plus its H1 level relative to the saw
recording on the same MIX channel. Other historical pitches were excluded from this choice.
The source-volume and routing metadata are unchanged across those recordings, but resistor,
pot/loading and device/source-level effects are not uniquely identifiable from those data.
9.53K replaces a diagnostic9.5K boundary point with a standard value inside the drawing's
verified tolerance. No output equalization or empirical audio/spectral lookup is involved.

Current-session MAIN round002(triangle),003(hybrid) and004(saw) are validation sources.
Each exact exported baseline/fitted preset is reloaded through the new offline MCP bridge.
Parameters, modulation fields, seed, tempo and frequency law must match the original
snapshot; only the source fingerprint changes. Existing knob fits are not refitted during
this model check. In particular, the old triangle fit's reduced cutoff can become too dark
after the source is corrected; its weak-partial union error is reported separately.

## Circuit and real-time propagation

The triangle table is regenerated by `ca72-lab tables`, retaining its generated TRI block
without unrelated filter/A440 changes. A full-board transient gives a triangle reset-area
change of approximately−2.2e−8V*s across2–10us extraction windows. Keeping the existing
real-time event convention changes `tri_glitch` from−3.8e−7 to−4.02e−7V*s. The buffer-area
change is below1e−9V*s, within the old `buf_lag` constant's precision. At220Hz the BR-only
change moves pitch by−0.000456cent, saw H1 by−0.0000097dB, and leaves resolved pulse duty
unchanged at65536 phase points. These are measured checks, not claims of exact identity.

The triangle's source impedance is approximately703–747ohm in DC rather than the old
constant687ohm. The hybrid's constant-port approximation is much closer; a full loaded
circuit test compares its actual real-time source with the nonlinear reference at volume8
and10. The approximation and any remaining source-port limitations are explicit.

LO's ideal triangle cannot reproduce the calibrated fold. It now uses two finite knees and
broad transistor curvature, fitted only to the ngspice-derived DC source voltage. Regenerate
with `python scripts/fit_light_triangle.py [tables.rs] [fit.json]` (NumPy only). Source DC RMS
error is1.43mV, maximum8.61mV; H2–24 approximation RMS is0.403dB. The finite knees use the
same integrated BLAMP kernel as the circuit oscillator, with separate physical reset step
and slope corrections. The lab's LO ideal-spectrum reference follows this source shape.
The existing oscillator aliasing budgets and fixed-knot CONTINUOUS identity check still apply.
LO retains its existing linear phase and omitted frequency-dependent core/reset details;
its approximation is not a second exact circuit solver. CPU changes are measured separately.

## Validation limits

Noise-qualified comparisons use the current gate-open round023 plus each take's local idle
floor. They include a partial when either source exceeds that conservative floor by10dB,
and report candidate-only excess and upper-band energy separately. A reference-only−60dBc
mask is a descriptive cutoff, not proof that weaker residuals are noise. No candidate gets a
pass merely for matching level, pitch, knob marks or one harmonic statistic.

The captured reference is oscillator1; oscillators2/3, other source levels and more notes
need further physical validation. Current graphs and listening candidates remain reviewable
experiments, with listening, weak-partial and upper-band differences retained.
