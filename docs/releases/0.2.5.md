# CA-72 0.2.5

A lighter start for new instances, and the resize pointer on macOS.

Watch and hear it: https://youtu.be/QLfwGqYg4wU

## Install

| Computer | Download |
|---|---|
| macOS 11 or later, Apple silicon or Intel | `CA-72-0.2.5-macOS.pkg` (signed and notarised; VST3, CLAP, Audio Unit and standalone application) |
| Windows 10 or 11, 64-bit | `CA-72-0.2.5-Windows-setup.exe` (VST3, CLAP and standalone application) |
| Windows 10 or 11, 64-bit, without an installer | `CA-72-0.2.5-Windows-x86_64.zip`: unpack it and follow its `README.txt` |
| Linux, x86-64 (Ubuntu 22.04, Debian 12, Fedora 36 or later, or Arch) | `CA-72-0.2.5-Linux-x86_64.tar.gz`: unpack it and run `./install.sh` |
| 0.1's factory presets, for any platform | `CA-72-0.2.5-0.1-presets.zip`: follow its `README.txt` |

Close your host, run the installer (it installs over earlier versions), then rescan your host's plug-ins. The standalone application is an optional installer component; on Linux, `--standalone-only` and `--plugins-only` select what to install. The Windows installer is not yet signed: when Windows says "Windows protected your PC", click **More info**, then **Run anyway**.

`SHA256SUMS.txt` lists checksums for the installers, Windows ZIP, retired presets and sources archive. `THIRD-PARTY-NOTICES.txt` contains third-party licences; `CA-72-0.2.5-git-sources.tar.gz` contains the git-pinned dependency sources. The CA-72's own source is this repository at v0.2.5.

## In this release

- **QUALITY starts at LO.** A new instance, and the standalone application's first session, plays Potato mode's light voices, 30 to 45 times lighter than HI, so the CA-72 runs on more computers from the start. Switch QUALITY to HI or ULTRA above POWER for the circuit's model. Your projects keep the QUALITY they were saved with, and projects from 0.1 open at HI, as before; presets don't change it.
- **The resize pointer on macOS.** Over the grip at the bottom right corner the pointer now shows resize arrows on macOS too, as it did on Windows and Linux in 0.2.4.

The sound engine, parameter identifiers and preset format are unchanged from 0.2.4. A host still cannot resize the editor by its window's edge. PR #40's Linux repaint experiment remains excluded; some Linux host/compositor combinations can still show a brief stretch when the window changes size.
