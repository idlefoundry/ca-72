# CA-72 0.2.7

Draft for the next release.

- **Steady pitch at ENTROPY 0 %.** ENTROPY now reaches below the previous minimum. From
  0 to 5 % it brings back the oscillators' small tuning mismatch, slow drift and waver.
  At 5 % it sounds as the old 0 % did; 5 to 100 % covers the previous range. New instances
  start at 5 %. The readout's OFF action goes to 0 %, and ON recalls its previous amount.
- **Existing sounds move to the new scale.** Old presets and saved projects load with
  ENTROPY translated by `new = 5 + 0.95 × old`. Factory presets store the new values.
  LOCK keeps working, and the panel's intentional pitch modulation still works at 0 %.

**Automation compatibility:** a DAW's automation lanes store normalised knob positions.
Those lanes cannot be translated by the plug-in: existing automation plays the new
mapping. In particular, an automated 0 % now gives steady oscillator pitch. Move old
automation values to `5 + 0.95 × old` if you want their previous ENTROPY amounts.

The factory presets render bit-identically to 0.2.6 in the comparison recorded in
R-ENTROPY-FLOOR. Arbitrary fractional amounts in old saved projects may differ by a
rounding bit when translated into the parameter's 32-bit value; the mapping is
mathematically equivalent, but exact equality for every fractional amount is not claimed.
