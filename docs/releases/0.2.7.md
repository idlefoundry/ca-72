# CA-72 0.2.7

Start from scratch, hold the pitch dead still, and see what's new.

## Install

| Computer | Download |
|---|---|
| macOS 11 or later, Apple silicon or Intel | `CA-72-0.2.7-macOS.pkg` (signed and notarised; VST3, CLAP, Audio Unit and standalone application) |
| Windows 10 or 11, 64-bit | `CA-72-0.2.7-Windows-setup.exe` (VST3, CLAP and standalone application) |
| Windows 10 or 11, 64-bit, without an installer | `CA-72-0.2.7-Windows-x86_64.zip`: unpack it and follow its `README.txt` |
| Linux, x86-64 (Ubuntu 22.04, Debian 12, Fedora 36 or later, or Arch) | `CA-72-0.2.7-Linux-x86_64.tar.gz`: unpack it and run `./install.sh` |
| 0.1's factory presets, for any platform | `CA-72-0.2.7-0.1-presets.zip`: follow its `README.txt` |

Close your host, run the installer (it installs over earlier versions), then rescan your host's plug-ins. The standalone application is an optional installer component; on Linux, `--standalone-only` and `--plugins-only` select what to install. The Windows installer is not yet signed: when Windows says "Windows protected your PC", click **More info**, then **Run anyway**.

`SHA256SUMS.txt` lists checksums for the installers, Windows ZIP, retired presets and sources archive. `THIRD-PARTY-NOTICES.txt` contains third-party licences; `CA-72-0.2.7-git-sources.tar.gz` contains the git-pinned dependency sources. The CA-72's own source is this repository at v0.2.7.

## In this release

### New

- **INIT in the preset drawer.** One click resets the sound to the CA-72's fresh-instance patch, ready to build a sound from scratch. Your player and computer settings (QUALITY, bend range, MIDI Learn, window size and the rest) stay as they are, and nothing is overwritten.
- **Steady pitch at ENTROPY 0 %.** ENTROPY now goes below its old minimum: 0 % holds the oscillators perfectly in tune, and 0 to 5 % brings back their small tuning mismatch, slow drift and waver. 5 % sounds exactly as the old 0 % did, and new instances start there.
- **Your sounds keep their character.** Presets and saved projects from earlier versions move to the new ENTROPY scale automatically and sound as they did.
- **The version you're running, in Settings.** The settings menu now starts with the installed version, whether or not the update check has run.
- **What's New.** The first time you open the CA-72 after an update, a short note lists what changed since the version you last used, including any releases you skipped. Close it and it won't appear again for this version; SETTINGS › WHAT'S NEW shows it any time.
- **Choose where the app installs.** The Windows installer asks where to put the standalone application, an external drive included; on Linux, `--prefix` moves the application alone; on a Mac, the app can be moved anywhere in Finder. Plug-ins always go where your host looks for them.

### Fixed

- **Mac, second monitor:** on a non-Retina monitor beside a Retina screen, the panel drew at half size in the corner of its window. It now fills the window on every screen, in every host.
- **Mac, standalone:** opened on a non-Retina monitor, the app's panel was wider than its window and cut off on the right. It now opens at its window's size on any screen.
- **Windows, standalone:** at display scaling above 100 %, the app's window was larger than its panel, with black space around it. The window is now exactly the panel at every scale. Like the Mac app, it is resized with the grip or WINDOW › SIZE rather than by dragging its frame.
- **Linux, standalone:** docks showed a gear instead of the CA-72's icon. The app now identifies itself to the desktop, error windows included. If you build from source, the README shows how to install the app's menu entry and icon.
- **CLAP:** a note sent with velocity zero by a host through CLAP's own note events stayed silent. It now plays.

**Automation and ENTROPY:** a DAW's automation lanes store knob positions, which the CA-72 can't translate, so existing ENTROPY automation plays on the new scale: an automated 0 % now means steady pitch. To keep an automated amount, set it to `5 + 0.95 × the old amount`.
