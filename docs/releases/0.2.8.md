# CA-72 0.2.8

Draft, not yet released. The release's contents and downloads are still being assembled.

## Install

Planned downloads, available when this release is published:

| Computer | Download |
|---|---|
| macOS 11 or later, Apple silicon or Intel | `CA-72-0.2.8-macOS.pkg` (signed and notarised; VST3, CLAP, Audio Unit and standalone application) |
| Windows 10 or 11, 64-bit | `CA-72-0.2.8-Windows-setup.exe` (VST3, CLAP and standalone application) |
| Windows 10 or 11, 64-bit, without an installer | `CA-72-0.2.8-Windows-x86_64.zip`: unpack it and follow its `README.txt` |
| Linux, x86-64 (Ubuntu 22.04, Debian 12, Fedora 36 or later, or Arch) | `CA-72-0.2.8-Linux-x86_64.tar.gz`: unpack it and run `./install.sh` |
| 0.1's factory presets, for any platform | `CA-72-0.2.8-0.1-presets.zip`: follow its `README.txt` |

Close your host, run the installer (it installs over earlier versions), then rescan your host's plug-ins. The standalone application is an optional installer component; on Linux, `--standalone-only` and `--plugins-only` select what to install. The Windows installer is not yet signed: when Windows says "Windows protected your PC", click **More info**, then **Run anyway**.

Checksums, third-party notices and sources will accompany the published release.

## In this release

### Fixed

- **Knobs, mouse and trackpad:** continuous knobs now follow every fraction of a drag or scroll, including precise trackpad and Magic Mouse deltas, instead of waiting for a whole scroll notch or the first three pixels of a drag. The travel and Shift's fine rate stay the same; RANGE, WAVEFORM, VOICES and other discrete options still step. This fixes the editor's input resolution; the audio response is assessed separately in #107.
