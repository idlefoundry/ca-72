# CA-72 0.2.8

Draft: notes are added here as this release's changes land. Its What's New entry in
`notes.toml` is due when the version is raised to 0.2.8 (`docs/whats-new.md`).

## Install

| Computer | Download |
|---|---|
| macOS 11 or later, Apple silicon or Intel | `CA-72-0.2.8-macOS.pkg` (signed and notarised; VST3, CLAP, Audio Unit and standalone application) |
| Windows 10 or 11, 64-bit | `CA-72-0.2.8-Windows-setup.exe` (VST3, CLAP and standalone application) |
| Windows 10 or 11, 64-bit, without an installer | `CA-72-0.2.8-Windows-x86_64.zip`: unpack it and follow its `README.txt` |
| Linux, x86-64 (Ubuntu 22.04, Debian 12, Fedora 36 or later, or Arch) | `CA-72-0.2.8-Linux-x86_64.tar.gz`: unpack it and run `./install.sh` |
| 0.1's factory presets, for any platform | `CA-72-0.2.8-0.1-presets.zip`: follow its `README.txt` |

Close your host, run the installer (it installs over earlier versions), then rescan your host's plug-ins. The standalone application is an optional installer component; on Linux, `--standalone-only` and `--plugins-only` select what to install. The Windows installer is not yet signed: when Windows says "Windows protected your PC", click **More info**, then **Run anyway**.

`SHA256SUMS.txt` lists checksums for the installers, Windows ZIP, retired presets and sources archive. `THIRD-PARTY-NOTICES.txt` contains third-party licences; `CA-72-0.2.8-git-sources.tar.gz` contains the git-pinned dependency sources. The CA-72's own source is this repository at v0.2.8.

## In this release

### Fixed

- **Standalone, quitting:** Command-Q did nothing in the Mac app, which had no menus. It now has a Mac app's menus (About, Hide, Hide Others, Show All, Quit; Window: Minimize, Close), and Command-Q, the Quit item, the Dock's Quit and logging out all close it cleanly, saving your session. On Linux, Ctrl+Q now quits; on Windows, Alt+F4 does, as before. These shortcuts work while TYPING or a name or value is being typed, and never play a note. Plug-ins are unchanged: your host's shortcuts stay your host's.
