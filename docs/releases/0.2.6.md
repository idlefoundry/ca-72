# CA-72 0.2.6

Same sound, lighter on your computer.

Watch and hear it: https://youtu.be/QLfwGqYg4wU

## Install

| Computer | Download |
|---|---|
| macOS 11 or later, Apple silicon or Intel | `CA-72-0.2.6-macOS.pkg` (signed and notarised; VST3, CLAP, Audio Unit and standalone application) |
| Windows 10 or 11, 64-bit | `CA-72-0.2.6-Windows-setup.exe` (VST3, CLAP and standalone application) |
| Windows 10 or 11, 64-bit, without an installer | `CA-72-0.2.6-Windows-x86_64.zip`: unpack it and follow its `README.txt` |
| Linux, x86-64 (Ubuntu 22.04, Debian 12, Fedora 36 or later, or Arch) | `CA-72-0.2.6-Linux-x86_64.tar.gz`: unpack it and run `./install.sh` |
| 0.1's factory presets, for any platform | `CA-72-0.2.6-0.1-presets.zip`: follow its `README.txt` |

Close your host, run the installer (it installs over earlier versions), then rescan your host's plug-ins. The standalone application is an optional installer component; on Linux, `--standalone-only` and `--plugins-only` select what to install. The Windows installer is not yet signed: when Windows says "Windows protected your PC", click **More info**, then **Run anyway**.

`SHA256SUMS.txt` lists checksums for the installers, Windows ZIP, retired presets and sources archive. `THIRD-PARTY-NOTICES.txt` contains third-party licences; `CA-72-0.2.6-git-sources.tar.gz` contains the git-pinned dependency sources. The CA-72's own source is this repository at v0.2.6.

## In this release

This update is all about performance. Every preset and project renders bit-identical to 0.2.5, so the sound hasn't changed at all; it just takes less of your computer to play.

- **HI is lighter.** When you play several voices (POLY or DOUBLE), HI now uses up to 17 % less CPU on a Mac and up to 9 % less on Windows and Linux.
- **Several instances play smoothly together.** Running more than one CA-72 in a project no longer makes the later ones stutter, and computers with more cores put them to use.
- **The panel rests when you can't see it.** On Windows and macOS, minimise a CLAP, VST3 or standalone window (or, on a Mac, hide or cover it) and the panel draws less often until you look again, saving CPU while your track plays. Audio Units keep drawing: GarageBand and Logic can show a remote view whose backing window says it is hidden.
- **Less background work on Mac.** An instance playing HI voices uses about a fifth of a core less while it waits for work.
- **ULTRA on powerful computers.** With six or more fast cores, ULTRA spreads each voice across several cores, so you can play a few voices live. It's still best for offline renders.

Nothing else changes: same presets, same controls, same project compatibility, and output bit-identical to 0.2.5.

*Tip: LO is the lightest mode and the default for new instances. HI is now lighter too, and ULTRA is meant for rendering.*
