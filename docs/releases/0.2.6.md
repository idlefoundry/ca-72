# CA-72 0.2.6

Less CPU for the same sound, and threads that follow the computer.

Watch and hear it: https://youtu.be/QLfwGqYg4wU

## Install

| Computer | Download |
|---|---|
| macOS 11 or later, Apple silicon or Intel | `CA-72-0.2.6-macOS.pkg` (signed and notarised; VST3, CLAP, Audio Unit and standalone application) |
| Windows 10 or 11, 64-bit | `CA-72-0.2.6-Windows-setup.exe` (VST3, CLAP and standalone application) |
| Windows 10 or 11, 64-bit, without an installer | `CA-72-0.2.6-Windows-x86_64.zip`: unpack it and follow its `README.txt` |
| Linux, x86-64 (Ubuntu 22.04, Debian 12, Fedora 36 or later, or Arch) | `CA-72-0.2.6-Linux-x86_64.tar.gz`: unpack it and run `./install.sh` |
| 0.1's factory presets, for any platform | `CA-72-0.2.6-0.1-presets.zip`: follow its `README.txt` |

Close your host, run the installer (it installs over earlier versions), then rescan your host's plug-ins. The standalone application is an optional installer component; on Linux, `--standalone-only` and `--plugins-only` select what to install. The Windows installer is not yet signed: when Windows says "Windows protected your PC", click **More info**, then **Run anyway**.

`SHA256SUMS.txt` lists checksums for the installers, Windows ZIP, retired presets and sources archive. `THIRD-PARTY-NOTICES.txt` contains third-party licences; `CA-72-0.2.6-git-sources.tar.gz` contains the git-pinned dependency sources. The CA-72's own source is this repository at v0.2.6.

## In this release

- **HI is lighter, and sounds exactly the same.** Two voices' filters are now solved together. With POLY or DOUBLE, HI uses about 15 to 17 % less CPU on Apple silicon (an M4 Pro) and about 5 % less on Intel and AMD (an i5-13600K on Windows, a Ryzen 7 7800X3D on Linux); all nineteen factory presets, ten voices. Every factory preset renders the same to the bit as in 0.2.5. A single voice without DOUBLE, LO and ULTRA are not affected.
- **More than one instance plays on time.** Instances now share the worker threads evenly, so a second or third CA-72 no longer runs late while the first holds every thread. Computers with more fast cores give the CA-72 more threads; the fewest stay as before.
- **ULTRA on stronger computers.** With six fast cores or more, ULTRA spreads a voice over six threads, so it can be played live with a few voices. The samples are the same as on one thread. ULTRA's first-time note now says what this computer does.
- **ULTRA with FEEDBACK or EXTERNAL INPUT is about 4 % lighter.** The OVERLOAD lamp's driver is worked out every eighth sample instead of every sample; the audio does not read it.

LO and HI sound the same to the bit as in 0.2.5, and ULTRA is unchanged; parameter identifiers, the preset format and installers are unchanged. A host still cannot resize the editor by its window's edge.
