# CA-72 0.2.3

Play the CA-72 without a DAW, with selectable audio and MIDI devices and a playable lower keyboard.

Watch and hear it: https://youtu.be/QLfwGqYg4wU

## Install

| Computer | Download |
|---|---|
| macOS 11 or later, Apple silicon or Intel | `CA-72-0.2.3-macOS.pkg` (signed and notarised; VST3, CLAP, Audio Unit and standalone application) |
| Windows 10 or 11, 64-bit | `CA-72-0.2.3-Windows-setup.exe` (VST3, CLAP and standalone application) |
| Windows 10 or 11, 64-bit, without an installer | `CA-72-0.2.3-Windows-x86_64.zip`: unpack it and follow its `README.txt` |
| Linux, x86-64 (Ubuntu 22.04, Debian 12, Fedora 36 or later, or Arch) | `CA-72-0.2.3-Linux-x86_64.tar.gz`: unpack it and run `./install.sh` |
| 0.1's factory presets, for any platform | `CA-72-0.2.3-0.1-presets.zip`: follow its `README.txt` |

Close your host, run the installer (it installs over earlier versions), then rescan your host's plug-ins. The standalone application is an optional installer component; on Linux, `--standalone-only` and `--plugins-only` select what to install. The Windows installer is not yet signed: when Windows says "Windows protected your PC", click **More info**, then **Run anyway**.

`SHA256SUMS.txt` lists checksums for the installers, Windows ZIP, retired presets and sources archive. `THIRD-PARTY-NOTICES.txt` contains third-party licences; `CA-72-0.2.3-git-sources.tar.gz` contains the git-pinned dependency sources. The CA-72's own source is this repository at v0.2.3.

## In this release

- **Standalone application.** Play the same instrument without a DAW using CoreAudio, WASAPI or ALSA. Open **Audio & MIDI** from settings to choose output, channels, sample rate, buffer size, optional external input and MIDI inputs. Unsaved sound edits, MIDI Learn, window size and working device choices are restored between sessions; held notes are released.
- **Playable lower keyboard.** The keyboard button beside Settings switches between the extra controls and a 44-key keyboard. Click or drag to play; use its octave buttons to move the visible range. The wheels, GLIDE and DECAY remain available.
- **Independent typing octaves.** In standalone, TYPING maps ASDFG to CDEFG, with black notes between. Z/X shifts its octave independently of the visible keys and oscillator RANGE controls. TYPING continues when the extra controls are shown or the lower panel is hidden. TYPING and PANIC are standalone controls; the plug-ins leave computer-keyboard input to the DAW.
- **Device selection and settings.** New sessions select the first unambiguously named MIDI input automatically. Existing explicit choices remain intact. Open selectors follow inventory changes; discovery errors retain the last good MIDI list and show an error. Unchanged settings show DONE, and edited settings show APPLY.
- **Consistent controls.** Keyboard headers and rail buttons share the control grid and button lettering; active panel and keyboard buttons use the illuminated finish.

The sound engine, parameter identifiers and preset format are unchanged from the corrected 0.2.2 release. This release does not claim a new DSP performance improvement. The separate Linux repaint experiment in PR #40 is excluded; some Linux host/compositor combinations can still show a brief stretch when the panel changes height.
