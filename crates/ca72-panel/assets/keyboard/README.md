# Keyboard materials

Original images generated with the built-in OpenAI image tool on 2026-10-13, from
the exact verbal prompts in `prompts/`. Copyright © 2026 Idle Foundry Ltd.,
GPL-3.0-or-later. Only these final sprites are built in, with original alpha preserved:

The renderer removes transparent padding in memory; the source files remain
unchanged. Each natural key has a deterministic L or T silhouette, clipped around
its neighbouring accidentals. Dark recessed spaces remain visible beside and in
front of each black key. Tops and fronts stay aligned; held notes add only a small
amber line, with fixed material illumination. Chassis surfaces use the editor's
existing walnut and painted-metal assets. The sprites contain no logos or legends.

The geometry and material study used the owner's supplied original Model D
photograph and these photographs of original instruments:

- [ToneTweakers late serial-number Model D](https://tonetweakers.com/products/moog-minimoog-model-d-late-sn).
- [LOFI 1974 Model D](https://lofimusic.com.au/products/minimoog-model-d-1974-vintage-analogue-vintage-monophonic-synthesiser-w-mods).
- [Early 1970s instrument at MIM Phoenix](https://commons.wikimedia.org/wiki/File:Minimoog_model_D_(early_1970s),_MIM_PHX.jpg).

Photographs were viewed for the study, never supplied to the generator or included
in these assets. No clone photographs were used. The 44-key span is F2 to C6 by
default. The white keys have neutral flat plastic tops, tight straight seams and
minimal front lips; glossy black keys have broad flat tops and planar front bevels.
Black-key width is 50% of the white-key pitch and height is 66% of the white-key
height. A continuous walnut board sits above the keybed.
