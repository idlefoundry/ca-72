# Test fonts

Fonts the stress packs carry (`packs/stress.rs`, BABEL; decisions.md R-SKIN-PACKS), to test a
pack's typeface: its licence scan, a wide face, and right-to-left legends. They are **test
files only**, never built into the plug-in. Each is under the SIL Open Font License 1.1, its
licence beside it (`OFL.txt`), as downloaded on 2026-10-16 from Google Fonts' repository,
unchanged.
